# GameOfLife
Project Summary
This project is a C# console-based simulation of Conway's Game of Life, designed to demonstrate object-oriented programming, grid-based logic, and console visualization techniques. The simulation runs for a fixed number of generations, displaying the evolution of cells based on simple rules.

# How to Run the Project
1- Open the solution in Visual Studio or any C# IDE.

2- Build the project.

3- Run the application from Program.cs.

# Project Structure
GameOfLife/
│
├── Program.cs       // Main entry point

├── Game.cs          // Simulation logic
├── Grid.cs          // Grid and update logic
├── Cell.cs          // Cell representation
└── README.md        // Project documentation
